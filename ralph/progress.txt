## Codebase Patterns
- API key stored in `groq_key.md` first line, read via `load_api_key()` in `main.py`
- Groq API accessed via `openai.OpenAI` client with custom `base_url`
- PRD stored in `ralph/prd.json`, progress in `ralph/progress.txt`
- Transcription via `client.audio.transcriptions.create(model, file, response_format='verbose_json', language='zh')` returns object with `.segments`
- Timestamps formatted as `**MM:SS**` using `seconds_to_mmss()` helper
- `SUPPORTED_FORMATS` and `MAX_FILE_SIZE` constants at module level for easy reference
